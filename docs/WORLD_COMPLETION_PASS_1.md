# GAIA Atlas — World Completion Pass I

**Version:** `2026-08-01.1`  
**Status:** Private development layer; unmerged, undeployed, and not promoted  
**Branch:** `agent/gaia-foundation`

## Purpose

World Completion Pass I responds to the first fresh-eye review of Release Candidate 1.

The review found that GAIA already had a strong identity, mature engineering, convincing exceptional-species logic, and four excellent ecological demonstrations. Its largest remaining weakness was not interface polish. It was uneven world depth:

- four deep regions did not yet make the planet feel broadly inhabited;
- full dossiers felt intentionally rich while shallow records could feel unfinished;
- GAIA Live represented only five migration routes;
- Observed behaved like a species checklist rather than a canonical field record;
- archive files looked like text cards instead of documents;
- the Index remained more ordinary than the rest of the institution.

This pass addresses those weaknesses without changing exact populations, existing routes, established dossiers, incidents, or signed Phase 3 ecology.

## Intentional publication tiers

Every species now presents as one of two complete publication tiers:

### Full GAIA Dossier

Extended civilian publication containing deeper analysis, founder notes, public advisories, archives, and cross-record ecology.

### Civilian Summary Record

A deliberately complete public record containing:

- publication scope;
- verified population and census date;
- primary geography and habitat;
- knowledge and access status;
- danger and conservation context;
- existing canonical biology or response sections when available;
- permanent-form population breakdown where relevant.

The previous sentence saying that a complete flagship dossier had “not yet been published” is removed from the public experience. A species no longer looks unfinished merely because it does not need a flagship dossier.

## GAIA Live world state

GAIA Live now represents more than five moving entities.

It combines:

- the five canonical date-driven migration routes;
- all six current regional seasonal conditions;
- active and peak habitat systems;
- active ecological corridors;
- a rotating set of causal ecological and infrastructure relationships.

All displayed state is deterministic. It derives from the real UTC calendar and existing regional seasonality rather than invented visitor activity or fabricated breaking news.

## Canonical observation model

Observed is rebuilt around an existing GAIA location instead of a species-only checkbox.

An eligible visitor now:

1. opens an Earth species record;
2. chooses one of its existing public canonical locations, or its current tracked route zone;
3. records the observation date automatically;
4. sees the location, location type, and date inside the Field Log.

Observations remain browser-local and never affect canon.

Observation is unavailable when:

- the record is Sealed;
- the species has no Earth location;
- the current record is Archived or Contact Lost;
- all locations are withheld, redacted, or otherwise unsuitable for civilian observation.

No new locations, free text, public sightings, uploads, or evidence claims are accepted.

## Archive reader

Linked dossier archives now open as readable in-universe documents.

The reader includes:

- archive code and classification;
- title and date;
- civilian abstract;
- subject, knowledge status, access, population, and geography cross-reference;
- previous and next document navigation;
- return to the subject dossier;
- a shareable archive deep link.

Archive search and existing deep links remain compatible with the new reader.

## Index completion

The GAIA Index now supports:

- category and realm;
- danger band;
- active-track, distributed-range, and fixed-site mobility;
- full dossier versus Civilian Summary Record;
- sorting by index number, population, danger, or species name;
- a live result summary;

This makes the Index feel like an institutional catalogue rather than a static table.
