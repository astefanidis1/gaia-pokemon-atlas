## Aegean ecological model

The field window treats the region as a connected but highly fragmented mosaic rather than one uniform biome:

- Attic–Cycladic maquis, olive terraces, and dry stone systems
- Pindus–Parnassus mountain refuges
- Northern Aegean wetlands and lagoons
- The Hellenic volcanic arc
- Crete–Dodecanese coastal karst and reef walls
- Historic ports, old cities, quarry belts, and archaeological custody sites

## Geometry policy

Regional geometry is ecological, not political. Public shapes are generalized where exact breeding caves, dens, refuges, singular anchors, or vulnerable colonies should not be exposed.

Habitat polygons describe sustained use. Corridors describe repeated movement between habitat systems. Neither changes signed global population canon.

## Canon boundary

This phase does not change:

- any exact species population;
- any singular legendary location;
- any existing seasonal route;
- any access classification;
- any personal Field Log behavior.

It deepens regional interpretation using the separate editorial layer.
